# FinQA Data Source

## Source

This project uses the official FinQA dataset: financial numerical-reasoning questions grounded in real S&P 500 earnings reports from 1999–2019.

- Official repository: https://github.com/czyssrs/FinQA
- Dataset paper: https://arxiv.org/abs/2109.00122
- Downloaded source revision: `0f16e2867befa6840783e58be38c9efb9229d742`
